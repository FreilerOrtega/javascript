# 📚 Curso de JavaScript – Freiler Ortega

Este repositorio contiene una colección de ejercicios desarrollados como parte de un curso de JavaScript. Cada carpeta representa un día de práctica con ejemplos de código y ejercicios que abarcan desde conceptos básicos hasta intermedios del lenguaje.

## 📁 Estructura del Proyecto

- `dia1/` a `dia13/`: Carpeta por cada día del curso con ejercicios individuales.
- `index.html`: Página principal para probar el código.
- `styles.css`: Estilos aplicados a los ejercicios HTML.
- `img/`: Imágenes utilizadas en los ejemplos.

## 🚀 Tecnologías Utilizadas

- **HTML5**
- **CSS3**
- **JavaScript (Vanilla)**
